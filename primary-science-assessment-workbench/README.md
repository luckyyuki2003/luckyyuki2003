# 评价设计工作台 · 小学科学（教科版）

面向小学科学教师与教研员的试卷质量评价和组卷工具。老师可以把现有试卷放入工作台，看清考了什么、考到什么层级、哪些题值得复核，并在修改后立即查看全卷指标的变化。

[在线体验（WorkBuddy）](https://www.workbuddy.link/p/KDdjCUSk3z7CvwSorbardK?source=2) · [查看 HTML 源码](index.html)

## 使用方式

下载本目录，保留 `index.html`、`workspace.css`、`workspace.js`、`cloud-config.js` 的相对位置，用现代浏览器打开 `index.html` 即可使用，也可以将整个目录静态托管。题库、样例和规则引擎仍内置在 HTML 中。试卷在浏览器本地解析与诊断。

2026-11-19 更新：新增个人试卷列表、本机自动保存、版本恢复和完整工程备份，并更新桌面与手机界面。当前不上云，无需注册；登录及跨设备同步接口暂未启用。浏览器数据清除后，本机存档无法恢复，请定期导出工程。详见 [修改记录](CHANGELOG.md) 和 [可选云端接入说明](CLOUD_SETUP.md)。现有 WorkBuddy 在线体验可能仍为旧版。

1. **评价现有试卷**。粘贴试卷，或导入 TXT / DOCX。工作台按题切分并识别题型、分值、内容点和认知层级，教师可逐题核对。
2. **查看诊断并调整**。从结构、知识点覆盖、认知层级、题型和情境五个维度检查试卷。规则提示附证据与编号，便于复核选项、答案、配分和整卷结构。可按提示替换或补题，修改后自动重算指标。
3. **按需求组卷**。用一句话描述册次、单元、时长、总分和难度取向，生成试卷结构与双向细目表。也可直接在表格中按“内容点 × 认知层级”指定题数，由系统从题库选题并提示缺口。
4. **管理题库与导出**。导入题目后可核对自动标注的内容点和层级。完成的试卷支持导出 Word（可选是否含答案），也可通过浏览器打印或另存为 PDF。

## 评价依据

- **学科题库**使用教科版小学科学试题，记录内容点、认知层级、预估难度和题库编号。
- **课程标准映射**以《义务教育科学课程标准（2022 年版）》为依据。工作台以项目设定的内容点与层级权重作比较基准，并展示本卷占比。
- **命题规则**在浏览器内执行确定性检查，覆盖选项设计、答案与配分、题干与层级、整卷结构。
- **测量学口径**用于组织难度和权重等指标。题库难度是设计阶段的预估值，实测难度与区分度需结合学生作答数据计算。

## 体验示例

| 场景 | 可以这样操作 |
| --- | --- |
| 一句话组卷 | 输入“四年级上册《声音》单元测验卷，40 分钟，100 分，基础题多一点”。查看双向细目表和内容点覆盖提示。 |
| 试卷质量评价 | 粘贴一份已有试卷，查看各内容点的实际占比、参考占比和需人工复核的题目。 |
| 定表组卷 | 为“呼吸与运动的关系”和“人体的消化器官”各设置一道题，查看取题结果，按需换题后导出。 |

## 开发验证

安装 Node.js 与依赖后执行 `npm test`。Windows 使用已安装的 Microsoft Edge；其他系统先执行 `npx playwright install chromium`。测试会启动临时本地服务（端口 8765），验证本机工作空间、既有规则引擎、手机布局及模拟云端场景，不连接真实云服务。截图写入 `.test-artifacts/`。
